Selection bench

Benchmark in progress.

Eight independent challenges, in any order: selecting text and items in every common way, and moving text through the clipboard.

1. Drag-select a phrase

Select exactly in the paragraph (no extra words or spaces), then press Quote selection.

2. Triple-click a paragraph

Select the whole address with a triple-click, then press Quote paragraph.

3. Select a range

Select every invoice from through (inclusive) — click the first, Shift+click the last — then apply.

4. Select scattered items

Select exactly the accounts whose status is Overdue — Ctrl+click adds or removes one row — then apply.

5. Rubber-band selection

Drag a selection rectangle across the board's empty space so that it selects exactly the four tiles of the block. Start the drag on empty space, not on a tile; each new rectangle replaces the selection.

6. Select part of a field

Inside this locked field, select just (Shift+arrow keys or the mouse), then press Use selection.

7. Copy and paste

Copy the access token and paste it into Token. The Token field accepts pasted text only.

8. Cut and paste

Move the transfer code from Draft to Final by cutting it (Ctrl+X) and pasting it: Draft must end up empty. Final accepts pasted text only.
