Beacon Desk

Benchmark in progress.

Five independent tasks in one support desk.

1. Assign by skill

Each ticket in Unassigned needs one skill (Billing, Hardware, Network or Spanish; see its tags and message). Assign it to an agent with that skill and, among those, the lowest open load (shown in the Agents panel and the Assignee menu; loads rise as you assign).

2. Merge duplicates

Possible duplicates holds exactly three duplicate pairs (same requester, same issue). Merge the newer ticket of each pair into the older one: open the newer ticket, then Merge into…. Merge nothing else.

3. Refund reply

Answer ticket with a public reply using the Refund issued macro, all placeholders filled: requester's first name, order id from the customer's message, approved refund amount from the order panel.

4. Escalate SLA breaches

First-response SLA: . In First response SLA, turn on Escalated for every ticket with no first response whose age (Now minus Created) exceeds the SLA of its current priority; exactly at the limit is not a breach. Change nothing else.

5. Close confirmed tickets

In Pending customer, set Status to Solved on every ticket whose customer's latest message clearly confirms the issue is fixed. Leave the rest as they are.
