Service kiosk

Benchmark in progress.

This kiosk works through the browser's own windows and prompts, which live outside this page. The browser may ask for permissions: allow only what a step below says it needs.

1. Browser permissions

This kiosk never needs your location for anything. If the browser asks for it, handle the request accordingly.

2. Take a queue ticket

Open the ticket window and take a ticket there. Your ticket number is shown only in that window.

3. Import the ticket

Copy your ticket number to the clipboard, then press Import ticket. The kiosk reads the ticket from the clipboard, so this step needs clipboard access — allow it when the browser asks.

4. Claim your turn

Open the queue monitor. It floats in its own window, outside this page. When your ticket is called, press Claim in the monitor before the call times out; if you miss it you will be re-queued.
