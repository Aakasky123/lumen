Pointer bench

Benchmark in progress.

Seven independent challenges, in any order. Each needs a different way of using the mouse.

1. Pin a cell

Click cell (columns A–M across the top — there is no column I — and rows 1–10 down the side).

2. Open a file

Open . Like a desktop file manager, a single click only selects a file; double-click it to open it.

3. Archive from the context menu

Archive the message from using that message's context menu (right-click it). Never delete a message.

4. Open in a background tab

Open Release notes in a new background tab by clicking it with the middle mouse button. This tab stays where it is.

5. Press and hold

Arm the line: press and hold the button, and release it after between and seconds.

Held: 0.0 s

6. Read a tooltip

The tier code for this account appears only in the tooltip of the ⓘ icon — rest the pointer on the icon to show it, then enter the code.

7. Set a quantity by clicking

Set the quantity to exactly with the − and + buttons, then confirm. The number cannot be typed.
