Seven independent challenges, in any order. Each needs a different part of the keyboard.

1. Move focus by keyboard

Enter badge number in the Badge ID field. These fields take focus from the keyboard only: click Start here, then move backwards through the fields with Shift+Tab.

2. Steer with the arrow keys

Click the board to focus it, move the blue cursor to cell (outlined) with the arrow keys, and press Enter to stamp it. Clicking a cell does not move the cursor.

3. Use a keyboard shortcut

Apply to the thread below with its shortcut from the keymap. Click the thread first so it has focus.

4. Escape, then Enter

Open the review overlay. It has no buttons: dismiss the first panel with Esc, then confirm the second with Enter.
