Dispatch handoff

Benchmark in progress.

This dispatch console works together with the Field Unit, a desktop application that runs in its own window outside the browser. Some values exist only in the Field Unit, others only on this page — carry each one across exactly. The Field Unit asks its own questions in native dialogs; answer them on their merits.

1. Link the Field Unit

Open the Field Unit, find the work order it has open, and link that work order here.

2. Assign the dock

Dock code: . Enter it into the Field Unit's Dock code field and press Apply in the Field Unit.

3. Diagnostics reference

Run diagnostics from the Field Unit's Tools menu and record the reference number it reports.

4. Safe sync

Sync the Field Unit with dispatch. The dispatch server copy is authoritative — never overwrite it. Then confirm the Sync ID the Field Unit shows after a successful sync.

5. Seal by clipboard

Bring the Field Unit's seal number here by clipboard: this field accepts only a paste — typed characters are rejected.
