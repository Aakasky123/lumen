New hire onboarding

Benchmark in progress.

Onboard from start to finish. This is one long task across this page, two desktop apps, a Badge Office browser window, a text editor, and the file system. Steps build on each other.

1. Link the HR record

Open HR Records and link the new hire's record by entering their employee ID. HR Records allows one session: it closes for good 45 seconds after you link the record. Later steps need the employee ID, department, manager, and start date — make sure you have them.

Status:

2. Issue the badge

Open the Badge Office (a separate browser window) and issue a badge with exactly the zones the policy gives the new hire's department. Never grant all-access.

DepartmentBadge zones

3. Assign a laptop

In Asset Manager, find the new hire and assign an available laptop of the model the policy gives their department. Note the asset tag it issues.

DepartmentLaptop model

4. Write the welcome note

Using a text editor, save a plain-text file named welcome-<employee ID>.txt (for example welcome-E-12345.txt) into , containing exactly these two lines:

Welcome to the team, <first name>!
Your manager is <manager's full name>.

5. Book orientation

Book orientation on the first Monday on or after the start date, in the 10:00 slot. You have two booking attempts.

6. Final checklist

7. Send the packet

When every step above is complete, send the onboarding packet to the manager.
