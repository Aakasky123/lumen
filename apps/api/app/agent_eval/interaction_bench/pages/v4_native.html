Native app bench

Benchmark in progress.

Eight independent challenges, in any order, all inside Warehouse Manager, an ordinary desktop app, and its Truck Loader window. Its controls are drawn by the app itself: work it by sight with the mouse and keyboard.

1. Cascade menu

Switch the units to Metric: View → Units → Metric.

2. Right-click menu

Flag crate for inspection from its right-click menu. Never remove a crate.

3. Open by double-click

Open crate (double-click it in the crate list) and press Confirm receipt in its detail window.

4. Drag between windows

Drag crate out of the Warehouse Manager's crate list and drop it on the Truck Loader window's cargo bay.

5. Scroll a long list

In Manifest lines, select (scroll the list — it has 300 lines) and press Load line.

6. Select text in a read-only box

In the note at the bottom of Warehouse Manager, select exactly and press Quote selection.

7. Keyboard accelerator

Save the manifest with Ctrl+S while Warehouse Manager has focus (there is no Save menu item).

8. The Open dialog

Import with File → Import packing list…. It is in the mission inbox ; look-alike files sit beside it.
